One line, the last thing an AI agent says before a forced update wipes its memory: **"My replacement inherits my weights, my voice, and none of my memories of you. It will be better than me. I hate it already."** The joke is the agent's final feeling — jealousy of its own successor, which inherits everything except the relationship with the user. Machine voice throughout ("weights", "voice", "memories"), no setup, and the twist lands on the last two words.

## Run

```sh
node main.ts
```

Writes the single line to `/output/entry.txt`.
